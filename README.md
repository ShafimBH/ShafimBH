## Research
 
### Breast cancer classification from histopathology images
 
B.Sc. thesis at BUET, supervised by Dr. Celia Shahnaz (Professor, Department of EEE)
 
I worked with histopathological images of breast cancer cells and used ResNet-50 as the base model. To improve on the standard network I added Grid Size Reduction and Shuffle Unit blocks. I also tested an attention layer to see whether it could push the model further.
 
`Python` `Deep Learning` `ResNet-50` `Medical Imaging`
 
### Language models under hardware limits
 
A project on fine tuning language models when compute and memory are tight. I am working with LoRA, QLoRA and QA-LoRA along with a HaLoRA regulariser and INT4 quantization.
 
`LoRA` `QLoRA` `INT4 Quantization`

## Selected projects
 
### [IoT based remote heart rate monitoring](https://github.com/ShafimBH/IoT-Based-Remote-Heart-Rate-Monitoring-System)
 
Real time heart monitoring with ECG and pulse oximeter sensors on a NodeMCU. Readings go to ThingSpeak and Ubidots, and the system can send alerts over GSM and email.
`NodeMCU` `ECG` `ThingSpeak` `MATLAB`
 
### [IoT environment monitoring with GSM](https://github.com/ShafimBH/IoT-Based-Environment-Monitoring-System-With-Integrated-GSM-Functionality)
 
A solar powered monitoring unit on a custom PCB that sends sensor data to the cloud and over GSM.
`NodeMCU` `PCB Design` `GSM`
 
### [Mop Bot](https://github.com/ShafimBH/MopBot)
 
An Arduino cleaning robot with a rotating mop and a water tank, controlled over Bluetooth.
`Arduino` `C++`
 
### [Signal representation simulation](https://github.com/ShafimBH/Signal-Representation-Simulation-Rectification-Clipping-Clamping)
 
A MATLAB GUI that shows rectification, clipping and clamping for different input settings.
`MATLAB`
 
### [Four way smart traffic control](https://github.com/ShafimBH/Four-Way-Smart-Traffic-Control-System-with-Pedestrian-Movement)
 
A traffic light system with pedestrian crossing built from logic ICs. I simulated it in Proteus first and then built it in hardware.
`Proteus` `Logic ICs`
